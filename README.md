# perl-class-inspector-feedstock

This repository is the conda recipe for [Class::Inspector](https://metacpan.org/pod/Class::Inspector), a Perl module that inspects classes: inheritance, methods, and related structure.

Upstream source: [CPAN Class-Inspector](https://metacpan.org/release/Class-Inspector) · [GitHub](https://github.com/plicease/Class-Inspector)

## Package contents

The resulting package installs the `Class::Inspector` and `Class::Inspector::Functions` modules for use with the `perl` package in the same environment.
